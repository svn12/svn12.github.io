🔧 Iframe 解鎖器擴充套件

本擴充套件用於解決在特定網站中嵌入群益等看盤網站時，遇到的 X-Frame-Options 或 Content-Security-Policy 阻擋問題。

📥 下載擴充套件 ZIP 檔

🛠️ 安裝教學（僅限電腦版 Chrome/Edge）

  1. 點擊上方按鈕下載 iframe_unblocker_ext.zip，並在電腦上將其解壓縮為一個資料夾。
  2. 開啟 Chrome 瀏覽器，在網址列輸入 chrome://extensions/ 並按下 Enter（若是 Edge 瀏覽器請輸入 edge://extensions/）。
  3. 在該頁面的右上角（或左下角），將 「開發人員模式」 的開關打開。
  4. 點擊左上角的 「載入未封裝項目」（Load unpacked）。
  5. 選擇你剛才解壓縮出來的那個資料夾（資料夾內應包含 manifest.json 等檔案）。
  6. 安裝完成！重新整理你的網頁，原本被擋住的 iframe 畫面就會正常顯示囉！

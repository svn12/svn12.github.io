2. 直播片頭滑鼠點選與防誤觸架構

🔒 現場操控與防誤觸分層設計

為兼顧轉播現場隨手切換全螢幕與換底圖的高效操控，同時杜絕晃動滑鼠誤觸彈出新分頁，片頭系統採用精確分層點選機制：

🟢 常態有效區塊 (Always 有效，無論鎖定與否)

  • 右上角日期時間 點擊直接同頁切換場次：點擊右上角（如 20261018 10:30），同頁跳轉切換華語與台語禮拜（location.href 不開新分頁），游標常態顯示手指指標。
  • 下方跑馬燈文字 點擊手動更換背景底圖：點擊底部跑馬燈字幕（#scrollText），立即淡入切換至下一張背景照片（setImage），游標常態顯示手指指標。
  • 畫面空白處 Full Screen TOGGLE 全螢幕切換：滑鼠左鍵點擊畫面任意非互動空白處（底圖背景、容器周圍），即時切換全螢幕模式（未全螢幕時進入全螢幕並播放片頭音樂；已全螢幕時退出全螢幕並暫停音樂）。

🔒 受保護外部連結區塊 (Default 鎖定，按 Key "T" 切換解鎖)

  • 受保護對象：
    • 中間講道資訊卡（.text-block ➔ 點擊開 Google 試算表）
    • 教會名稱連結（#church ➔ 點擊開 YouTube 頻道）
    • 週報下載連結（#barcode QR Code 與 #CurTime 左側時間 ➔ 點擊開週報網頁）
  • 預設 Default 鎖定：上述區塊點選全面鎖定無效，游標自動呈現一般箭頭（default），防止誤觸跳轉，亦不觸發全螢幕切換。
  • 按鍵 T 切換解鎖：按鍵盤 T 鍵可隨時切換受保護區塊之解鎖狀態：
    • 解鎖狀態下右下角 HUD 提示：🔓 滑鼠點選已全部啟用 (按 T 鎖定)，游標恢復手指指標。
    • 鎖定狀態下右下角 HUD 提示：🔒 滑鼠點選已鎖定 (僅右上角有效，按 T 解鎖)。

3. 鍵盤快捷鍵對照表

按鍵 功能 詳細說明
T 點選鎖定切換 切換外部連結區塊之「防誤觸鎖定」與「全部點選啟用」
Space 播放 / 暫停 片頭循環背景音樂無縫播放與暫停切換（未全螢幕時自動進入全螢幕）
↑ (ArrowUp) 音量增加 (+10%) 每次增加 10%，最高至 100%；若處於靜音會自動解除
↓ (ArrowDown) 音量降低 (-10%) 每次降低 10%，最低至 0%（安全無聲，背景音軌持續循環）
M 靜音開關 一鍵快速切換靜音與取消靜音
F 全螢幕切換 進入或退出瀏覽器全螢幕模式 (TOGGLE)
C 前往排版助手 一鍵直跳「主日排版助手 (多功能整合工作台)」網頁
H 快捷說明 於右下角浮水印顯示微型快捷鍵速查卡，3 秒後平滑淡出

4. 主日排版助手直播輔助功能

📖 1. 聖經經文「📋 直播複製格式 (C3/C4)」
  • 免選譯本，直接輸出：選擇「直播複製格式」時，系統自動並行抓取「聖經公會巴克禮台漢本 (tghg)」與「和合本 2010 (rcuv)」。
  • C3 / C4 雙方塊與獨立複製：右側預覽區自動顯示 🟩 台語聖經 (C3 格子專用) 與 🟦 華語聖經 (C4 格子專用)，上方附專屬複製按鈕，格式為每行以簡寫書卷+章:節開頭（如 弗4:11 ...，無空行），一鍵直貼試算表對應儲存格。
  • 章節同章自動連動：起點選擇章（或詩篇篇數）後，終點章自動同步為同一章節，徹底杜絕跨章錯誤。
🖼️ 2. 「直播片頭背景」圖庫管理
  • 直傳 Google Drive：支援拖曳圖檔或直接剪貼簿貼上 (Ctrl+V)，自動轉為 1920 高清直連網址並寫入清單。
  • 一鍵複製純網址 (G2)：點擊「📋 一鍵複製整組照片純網址」，格式為 Tab 分隔純網址，可直接於 Google 試算表 G2 儲存格橫向貼上。

5. 底層穩定與安全機制

  • 雙圖層 1.8 秒平滑交錯漸變 (Crossfade)：背景大圖非同步預載完成後才切換透明度，徹底根除外網載入延遲與閃白問題。
  • 三層斷網防白屏容錯：當外部 Google 試算表 API 異常或離線時，系統自動啟用 LocalStorage 快取與保底資料，確保轉播畫面持續不中斷。

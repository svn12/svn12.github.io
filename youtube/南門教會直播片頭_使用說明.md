## 2. 直播片頭滑鼠點選與防誤觸安全機制 (全新)
為兼顧轉播現場的流暢操控與防止導播誤觸畫面跳轉，片頭系統採用分層點選邏輯：

### 🟢 常態有效區塊 (Always 有效，無論鎖定與否)
1. **右上角日期時間區塊 (`#Bdate`)**：點擊直接於同頁切換「台語禮拜」與「華語禮拜」，游標常態為手指指標（`pointer`）。
2. **下方跑馬燈文字 (`#scrollText`)**：點擊直接手動切換至下一張背景圖（`setImage`），游標常態為手指指標（`pointer`）。
3. **畫面空白處 (Background / 任意非互動區)**：點擊作為 **Full Screen TOGGLE** 切換（未全螢幕時點擊進入全螢幕並播放片頭音樂；已全螢幕時點擊退出全螢幕並暫停音樂）。

### 🔒 受保護外部連結區塊 (Default 鎖定，按 Key "T" 切換解鎖)
- **保護對象**：
  - 中間講道資訊方塊 (`.text-block`，包含題目、講員、經文 ➔ 點擊開 Google 試算表)
  - 教會名稱連結 (`#church` ➔ 點擊開 YouTube 頻道)
  - 週報下載連結 (`#barcode` QR Code 與 `#CurTime` 左側時間 ➔ 點擊開週報)
- **預設狀態 (Default 鎖定模式)**：
  - 上述區塊點選**全面鎖定無效**，游標自動呈現一般箭頭（`default`），不會觸發跳轉，亦不會誤觸全螢幕 TOGGLE。
- **解鎖切換 (按 Key "T")**：
  - 按鍵盤 **`T`** 鍵：隨時切換受保護區塊的鎖定狀態。
  - 解鎖時右下角 HUD 提示：`🔓 滑鼠點選已全部啟用 (按 T 鎖定)`，受保護區塊恢復點選並呈現手指游標。
  - 鎖定時右下角 HUD 提示：`🔒 滑鼠點選已鎖定 (僅右上角有效，按 T 解鎖)`。

## 3. 鍵盤快捷鍵速查表
| 按鍵 | 功能 | 詳細說明 |
| :--- | :--- | :--- |
| **T** | **點選鎖定切換** | 切換外部連結區塊的「防誤觸鎖定」與「全部點選啟用」 |
| **Space** | **播放 / 暫停** | 音樂無縫播放與暫停切換（未全螢幕時會自動進入全螢幕） |
| **↑** (ArrowUp) | **音量增加 (+10%)** | 最高至 100%；處於靜音時會自動解除靜音 |
| **↓** (ArrowDown) | **音量降低 (-10%)** | 最低至 0%（安全無聲，背景循環不中斷） |
| **M** | **靜音開關** | 一鍵快速切換靜音狀態 |
| **F** | **全螢幕切換** | 進入或退出瀏覽器全螢幕模式 (TOGGLE) |
| **C** | **前往排版助手** | 一鍵直跳「主日排版助手 (多功能整合工作台)」網頁 |
| **H** | **快捷鍵說明** | 於畫面右下角顯示微型快捷鍵提示卡，3 秒後平滑淡出 |

## 4. 主日排版助手直播輔助功能
於 `sermon_ppt/index.html` 整合之直播作業功能：

1. **聖經經文「📋 直播複製格式」**：
   - **免選譯本**：選擇直播格式後自動並行抓取「聖經公會巴克禮台漢本」與「和合本 2010」。
   - **C3 / C4 雙方塊輸出**：右側即時產出 **🟩 台語聖經 (C3 格子專用)** 與 **🟦 華語聖經 (C4 格子專用)** 兩個卡片方塊。
   - **一鍵獨立複製**：點擊「📋 複製 C3 台語經文」或「📋 複製 C4 華語經文」，格式為每行以簡寫書卷+章:節開頭（無空行），直貼試算表 C3 與 C4。
   - **章節同章自動連動**：起點選定章/篇後，終點章/篇自動連動為同一章，杜絕手動輸入錯誤。

2. **「🖼️ 直播片頭背景」圖庫管理**：
   - **直傳 Google Drive**：支援圖片檔案拖曳上傳與剪貼簿 (Ctrl+V) 截圖粘貼，自動上傳至專屬雲端硬碟。
   - **一鍵複製整組網址 (G2)**：點擊「📋 一鍵複製整組照片純網址」，格式為 Tab 分隔純網址，可直接於 Google 試算表 `G2` 欄位橫向貼上。

## 5. 底層穩定與防護機制
- **雙圖層 1.8s 平滑漸變轉場 (Crossfade)**：背景輪播切換採非同步預載與雙圖層透明度漸變，保證不閃白、不黑屏。
- **三層斷網防白屏容錯**：Google 試算表 API 斷線時自動啟用 LocalStorage 本機快取與保底資料，畫面永不中斷。
